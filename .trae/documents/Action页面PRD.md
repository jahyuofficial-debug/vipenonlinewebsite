# Action页面产品需求文档

## 1. 产品概述

为Vipen网站创建一个Instagram风格的动态流页面（Action页面），用户可以无限向下滚动浏览丰富的视觉内容。页面模仿Instagram的feed流体验，包含图片/视频卡片、用户头像、点赞、评论、收藏等社交互动元素，以及Stories横向滚动栏。

## 2. 核心功能

### 2.1 页面模块
1. **Stories栏**：顶部横向滚动的用户Stories，带未读指示器
2. **Feed流**：垂直无限滚动的内容卡片
3. **互动操作**：点赞、评论、收藏、分享按钮
4. **加载更多**：滚动到底部自动加载/显示更多内容

### 2.2 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| Action | Stories栏 | 横向滚动，圆形头像+用户名，彩色未读边框 |
| Action | Feed卡片 | 用户头像+名称、图片/视频、互动按钮、点赞数、描述文字 |
| Action | 加载更多 | 滚动到底部自动加载新内容 |

## 3. 核心流程

用户进入Action页面 → 看到Stories栏和Feed流 → 可横向滑动Stories → 可纵向滚动Feed → 点击互动按钮 → 滚动到底部加载更多内容

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：深色模式（与网站整体黑色背景一致）
- **主色调**：#000000背景，#ffffff文字，#b2b9ff强调色
- **卡片样式**：无边框，轻微分隔线，圆角图片
- **字体**：Helvetica Neue, Arial, sans-serif
- **布局**：单列Feed，居中显示，最大宽度限制

### 4.2 页面设计概述

| 页面 | 模块 | UI元素 |
|------|------|--------|
| Action | Stories栏 | 圆形头像(56px)，彩色渐变边框(未读)，用户名标签 |
| Action | Feed卡片 | 用户头像(32px)+名称、9:16或4:3图片、互动按钮行、点赞数、描述文字 |
| Action | 互动按钮 | 心形(点赞)、对话气泡(评论)、书签(收藏)、纸飞机(分享) |

### 4.3 响应式
- 桌面端：单列居中，最大宽度470px
- 移动端：全宽显示

## 5. 预设内容

提供至少20条Feed内容和15个Stories用户，确保页面可以滚动很久。
