## 二、修复方案（分三期）

### 第一期：数据一致性 + 核心 Bug 修复（Issue 1-3, 8）

#### Issue 1-3：Disc 前后端数据不一致

**问题根因：**
- `data/disc.json` 只有 3 首曲目（酒精/翱翔/Young OG）
- ManagerGo 通过 `localStorage(vipen_mgr_disc_tapes)` 可添加更多曲目（如 5 首含"崂山道士"）
- 刷新页面后若 localStorage 被清除或数据损坏 → 回退到 JSON 的 3 首
- "崂山道士"无封面 → 显示破碎图片 icon
- 点击无响应 → `loadDiscTrack` 中 `tape.audio` 路径不存在

**修复方案：**

| 文件 | 变更 |
|------|------|
| `js/main.js` | 数据加载逻辑：优先使用 localStorage(vipen_mgr_disc_tapes)，**若为空则初始化为 disc.json 的默认数据，并自动写入 localStorage**，确保 ManagerGo 与前端共享同一数据源 |
| `js/pages/disc.js` | `loadDiscTrack()` 增加音频路径有效性检查：播放前 `fetch(HEAD)` 验证文件存在，不存在则 toast 提示并跳过 |
| `js/pages/disc.js` | 封面 `<img>` 增加 `onerror` 处理：图片加载失败时显示默认占位图或渐变色 |
| `js/pages/manager.js` | Disc 管理页面增加"同步至前端"按钮，确保 ManagerGo 的 localStorage 数据与前端一致 |
| `data/disc.json` | 保持为默认模板（3 首），后续所有管理操作都基于 localStorage |

#### Issue 8：ManagerGo Fresh 图片上传/更换失效 + Headline 不可点击

**问题根因：**
- `validateCoverImage()` 函数 (manager.js L73-95) 可能对 Fresh 的 bgImage 校验过严（最小 800×800 不适合横幅图）
- Fresh Headline 点击事件绑定在 `[data-fresh-hero-bg]` 元素上，若 bgImage 为空则无此元素可点

**修复方案：**

| 文件 | 变更 |
|------|------|
| `js/pages/manager.js` | Fresh 编辑器的背景图上传区使用独立的 `validateFreshImage()` 函数，放宽尺寸限制（最小 1200×400 适合横幅比例） |
| `js/pages/manager.js` | `bindImageUploadField()` 增加上传后即时提示（toast） |
| `js/pages/fresh.js` | Headline 点击增加容错：若 `[data-fresh-hero-bg]` 元素不存在，降级为整个 `.fresh-hero-content` 区域可点击 |

## 三、验证步骤

1. **Disc 数据一致性**：在 ManagerGo 添加曲目 → 刷新前端 Disc 页面 → 验证曲目数量一致、封面正常显示
2. **Disc 封面错误处理**：模拟上传无封面的曲目 → 前端应显示默认占位图而非破碎图标
3. **Fresh Headline 点击**：进入 `/` → 点击 Hero 轮播背景或卡片 → 应导航到 Hero 详情页
4. **Fresh 图片上传**：ManagerGo Fresh 编辑器中更换 bgImage → 保存后刷新主页 → 验证新图片生效
5. **Dashboard**：进入 ManagerGo Dashboard → QuickActions 区域已移除
6. **Design 图片上传**：ManagerGo Design 编辑器中可见 Fan Card Image 和 List Thumb Image 独立上传区
7. **Design 详情布局**：进入作品详情 → 顺序为封面→正文→文本描述→Tags→Like 按钮
8. **Fresh 图片注释**：编辑器插入图片 → 添加注释 → 保存 → 前端显示 figure+figcaption 结构
9. **Design Tools**：编辑器工具区不含 PS，含 Adobe Illustrator，可输入自定义工具名（≤10 字符）
10. **Settings**：Settings 页面只有 Contact/Title/Rights 三项，默认值正确
11. **Design 三步验证**：进入 Design 页面 → PIN 验证 → Creator Name 验证 → Company 验证 → 成功进入
12. **PIN 背景图**：所有 PIN 输入页显示统一的 PIN验证.png 背景

1. "崂山道士"曲目存在于 ManagerGo 的 localStorage 数据中（`vipen_mgr_disc_tapes`），需在刷新后保持一致性

4. 图片拖拽缩放为纯前端实现，保存时记录缩放后的 CSS width/height 属性在 img 标签上
5. 背景图路径 `D:\设计文档\Web素材\页面预设\PIN验证.png` 需要复制到项目 `images/` 或 `banner/` 目录下并通过相对路径引用
